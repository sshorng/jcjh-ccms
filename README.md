# 國中輔導個案管理系統（CCMS）

優先關懷個案名單與晤談紀錄管理系統。支援多校共用同一份前端程式，各校資料庫彼此獨立。

## 檔案說明

| 檔案 | 用途 |
|:---|:---|
| `index.html` | 系統主頁面（前端模板與樣式引用） |
| `ccms-app.js` | 前端邏輯（Vue 應用程式全部 methods / computed / data） |
| `ccms-style.css` | 樣式表 |
| `程式碼.js` | 後端（Google Apps Script，含試算表存取與權限控管） |
| `ccms_sample.xlsx` | 月報表匯出所用之官方空白範本 |
| `appsscript.json` | Apps Script 專案設定 |
| `.clasp.json` / `.claspignore` | clasp 部署設定 |
| `DEPLOY_GUIDE.md` | 給其他學校的部署操作指南 |

## 多校共用設計

本系統的前端（GitHub Pages）由所有學校共用，但**資料庫彼此獨立**：

- 校名儲存於各校自己的試算表「系統設定」工作表（`SCHOOL_NAME` 與 `SCHOOL_SHORT`）。
- 系統標題、登入頁、側邊欄與所有匯出檔（Word、Excel、ZIP）一律讀取該校設定值。
- 各校管理員登入後，於「系統配置 → 校名設定」即可修改，不需修改任何程式碼。

### GAS 網址解析優先序

1. 網址參數 `?config=`（由「產生快取分享網址」產生，對方首次開啟即寫入本機瀏覽器）
2. 瀏覽器本機儲存 `cms_gas_url`
3. 前端預設網址 `DEFAULT_GAS_URL`（`ccms-app.js` 第 8 行）

> 原開發學校（建成國中）直接使用預設網址，**無須任何設定步驟**。
> 其他學校才需要貼上自己的 GAS 網址，或由開發者提供快取分享網址。

### 快取分享網址

登入頁下方「⚙️ 系統設定」或「系統配置 → 校名設定 → 分享給其他學校」可產生分享網址，格式為：

```
<系統首頁網址>?v=<版本>&config=<base64(JSON)>
```

JSON 內容為 `{ u: GAS網址, n: 校名全名, s: 校名簡稱 }`。舊格式（base64 純網址）仍可正常解析。

## 部署

### 一、前端（GitHub Pages）
1. 將本倉庫設為 GitHub Pages 來源，branch 選 `main`、資料夾選 `/ (root)`
2. 開啟 `https://<帳號>.github.io/<倉庫名>/` 即可使用

### 二、後端（Google Apps Script）

一般使用者請直接複製範本試算表即可，**不需要貼程式碼**：

1. 開啟範本連結並建立副本：<https://docs.google.com/spreadsheets/d/1LMJjSneigBoprl4NClCReD8R5d0NLfTQt124vrrjRvA/copy>
2. 從副本的「擴充功能」→「Apps Script」
3. 「部署」→「新增部署作業」→ 類型「網頁應用程式」
4. 執行身分：自己；誰可以存取：任何人
5. 複製網址，回到系統 ⚙️ 設定貼上並測試連線

維護者若要手動建立，則將 `程式碼.js` 內容貼到 `Code.gs` 再部署。

詳細步驟請見 `DEPLOY_GUIDE.md`。

> 修改前端檔案後，請記得更新 `index.html` 內的版本參數（`?v=YYYYMMDDxx`），
> 否則瀏覽器會繼續使用舊的快取檔案。目前版本：`20261015h`。

## 角色權限
- **管理員**：全權限（帳號管理、系統配置、校名設定、所有個案）
- **行政**：可看／編輯所有個案，無帳號管理權限
- **專輔教師**：僅能看／編輯自己負責的個案（含共同輔導的個案）

## 多人共同輔導
個案的「專輔」欄可複選，以「、」分隔儲存於同一欄位，舊資料格式相容無需搬移。
- **先勾選者為主**，後勾選者為輔
- 主輔僅差在「網頁呈現、能否記錄、觀看個案紀錄」兩項皆可
- **報表輸出（月報表、導師回覆表、Word 匯出）一律歸屬主要專輔**，次要專輔不影響任何輸出
- 正式個案編號以主要專輔的教師編碼產生
