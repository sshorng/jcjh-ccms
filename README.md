# 建成國中輔導個案管理系統

優先關懷個案名單與晤談紀錄管理系統。

## 檔案說明

| 檔案 | 用途 |
|:---|:---|
| `index.html` | 系統主頁面（前端模板與樣式引用） |
| `ccms-app.js` | 前端邏輯（Vue 應用程式全部 methods / computed / data） |
| `ccms-style.css` | 樣式表 |
| `程式碼.js` | 後端（Google Apps Script，含試算表存取與權限控管） |
| `ccms_sample.xlsx` | 月報表匯出所用之官方空白範本 |
| `appsscript.json` | Apps Script 專案設定 |
| `.clasp.json` / `.claspignore` | clasp 部署設定 |

## 部署

### 一、前端（GitHub Pages）
1. 將本倉庫設為 GitHub Pages 來源，branch 選 `main`、資料夾選 `/ (root)`
2. 開啟 `https://<帳號>.github.io/jcjh-ccms/` 即可使用

### 二、後端（Google Apps Script）
1. 開啟 Apps Script 專案，將 `程式碼.js` 內容貼到 `Code.gs`
2. 「部署」→「新增部署作業」→ 類型「網頁應用程式」
3. 執行身分：自己；誰可以存取：任何人
4. 複製網址，回到系統 ⚙️ 設定貼上

> 修改前端檔案後，請記得更新 `index.html` 內的版本參數（`?v=YYYYMMDDxx`），
> 否則瀏覽器會繼續使用舊的快取檔案。

## 角色權限
- **管理員**：全權限（帳號管理、系統配置、所有個案）
- **行政**：可看／編輯所有個案，無帳號管理權限
- **專輔教師**：僅能看／編輯自己負責的個案（含共同輔導的個案）

## 多人共同輔導
個案的「專輔」欄可複選，以「、」分隔儲存於同一欄位，舊資料格式相容無需搬移。
- **先勾選者為主**，後勾選者為輔
- 主輔僅差在「網頁呈現、能否記錄、觀看個案紀錄」兩項皆可
- **報表輸出（月報表、導師回覆表、Word 匯出）一律歸屬主要專輔**，次要專輔不影響任何輸出
- 正式個案編號以主要專輔的教師編碼產生
